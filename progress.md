### 01 - Hello World ✅

### 02 - Variables & Types ✅
- Concepts: immutability by default, mut, basic types (i32/u32/f64/bool/char/&str), type inference, shadowing vs mutation, stack vs heap intro
- Key understanding: `let` creates, `=` mutates. Shadowing is not mutation — it drops and recreates. Stack = fixed/fast, heap = flexible/managed. Rust manages both via ownership (no GC).
- Date: 2026-03-17

### 03 - Functions ✅
- Concepts: function syntax, mandatory parameter types, return types, expressions vs statements, last expression as return value, early return, if as expression, side-effect functions, blocks as expressions
- Key understanding: Semicolons turn expressions into statements. Functions return their last expression. `return` is only for early exit. Functions with no return type exist for side effects.
- Date: 2026-03-17
